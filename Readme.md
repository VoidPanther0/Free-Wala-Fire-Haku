# Sachin Dev

A Windows overlay DLL (DirectX 11 + ImGui) providing an in-game settings menu and ESP
overlay for the Free Fire emulator.

## Features
- ImGui-based settings panel with Aimbot, Visuals/ESP, Loader and Config tabs
- Player ESP: boxes, skeleton, health bars, tracers, snaplines, names, distance
- Smooth UI scaling, search, color pickers, slide-out option popups
- Emulator (BlueStacks) connection via ADB + BstkVMM hook

## Build
- Open `ImguiPortifolio15.sln` in Visual Studio 2022
- Configuration: Release / x64
- Output: `bin/Sachin Dev.dll`
